The rule "a board or tooling card is Quick unless it touches the Worker, the hooks, permissions or the Mac" lived in the lead's memory, and a launchd change was set Full by hand. The mechanism is the one of #C897 (`collector/review-paths.mjs`, a repository's `reviewPaths`), which already reads `collector.repos[].reviewPaths`; this card adds the board repository's table (`docs/review-paths-board.md`: `worker/`, `gate/`, `hooks/`, `keeper/`, the install, hook, deploy and land scripts, `wrangler`, `.github/`, `.claude/`, plist and settings files, `package.json`) and pins it against the engine: a Quick card that touches one has Security's review, one that touches none keeps the typed rule, a Full card is never lowered, a pattern is anchored. The reviewers added the deploy pair, the pins, `.githooks/`, the scripts that decide who reviews or that a model acts on, and `page/`; `collector/**` as a whole stays Quick for now (the owner decides). The level a card shows reads Full whenever Security's review is in play on it, whatever was typed (`shownLevel`, `worker/compat-view.mjs`: a Worker deploy). The table takes effect when the owner's config carries it on the `flight-board` entry of `collector.repos` (a config change is read only from a signed commit, #C974). Ships: a Worker deploy, and a config line. Tests: `tests/review-level-from-paths-board.test.mjs`.

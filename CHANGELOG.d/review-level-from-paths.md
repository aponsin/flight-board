- The board's own repository has a table of the paths that need Security's review (review-level-from-paths, #C1108). The rule "a board or tooling card is Quick unless it touches the Worker, the hooks, permissions or the Mac" lived in the lead's memory, and a launchd change was set Full by hand. The mechanism is the one of #C897 (`collector/review-paths.mjs`, a repository's `reviewPaths`), which already reads `collector.repos[].reviewPaths`; this card adds the board repository's table (`docs/review-paths-board.md`: `worker/`, `gate/`, `hooks/`, `keeper/`, the install, hook, deploy and land scripts, `wrangler`, `.github/`, `.claude/`, plist and settings files, `package.json`) and pins it against the engine: a Quick card that touches one has Security's review, one that touches none keeps the typed rule, a Full card is never lowered, a pattern is anchored. The table takes effect when the owner's config carries it on the `flight-board` entry of `collector.repos` (a config change is read only from a signed commit, #C974). Ships: nothing to install; a config line. Tests: `tests/review-level-from-paths-board.test.mjs`.

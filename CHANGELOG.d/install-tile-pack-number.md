- A board card's Pack and Install tiles name the pack that first held its landing ("pc111", with "installed" or "pair built" after it on a laptop; a phone shows the number alone), and a product card's Live tile names the version it shipped in ("v1.226.10"), so you can check them against what you installed (install-tile-pack-number, #C1309). The probe reads the pack number from the pair folder and git (the oldest pair whose pin holds the card's landing, found with a handful of git questions), and the state's schema takes it as `pack`. Ships: a page publish, and the owner's pack (the probe's pinned files `collector/pairs.mjs`, `collector/state.mjs`, `collector/state-schema.mjs`), so the number shows after the next pack is installed. Tests: `tests/install-tile-pack-number.test.mjs`, `tests/pack-install-lit-by-evidence.test.mjs`, `tests/landed-wakes-pack-build.test.mjs` (mutation-checked).

- A client that cannot type `changes_definition` can still create a flight-board card (card-names-its-contract, #C1169 follow-up). On 11-17 no session could create a flight-board card: the tool list a session holds predates the schema that names `contract` and `changes_definition`, so the boolean reached the Worker as the text "false" and was refused. At the tool door `card_create` and `card_update` now read exactly the text "true" and "false" as the booleans; any other text ("yes", "1", an empty one) is still refused with `card-flag`, and `true` still needs `from_thread`. The rule itself is unchanged. Ships: a Worker deploy. Tests: `tests/card-names-its-contract.test.mjs`.

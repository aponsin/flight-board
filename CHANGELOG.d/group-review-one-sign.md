- A group of cards gets one sign-off, and a stack's lower commits can no longer go out unsigned (group-review-one-sign #C1032; the owner chose A on 2026-11-12: grouping must save reviews, not only installs). The release tool (`scripts/board-release.mjs`) used to read the tip's own Checker and Security notes only. Now every commit of `origin/main..tip` needs, per role (Checker's PASS in `refs/notes/checker`, Security's SECURE in `refs/notes/security`, each independent), a note of its own or that role's line note on the tip: a first line `PASS ... line from <40-hex base>` (or `SECURE ...`), covering base..tip. That is the #C934 line note, now accepted for every commit in the range, not only for judging a waiting pack. A line note counts when its base is an ancestor of `origin/main` and of the tip and is where the tip's line left main (never main's own commits), base..tip has no merge commit and at most 30 commits; otherwise it covers nothing and the dry run says why. A moved tip is not covered (the note is on the exact tip). A commit in the range with its own note whose first line is not PASS/SECURE (FINDINGS, RISKS, STOP, a withdrawal) refuses even under a valid line note on the tip (this reverses #C934, where a line sign on the tip covered a lower pack with its own FINDINGS; the two end-to-end tests in `tests/stack-sign-covers-line.test.mjs` are updated to say so). A PASS line in the security ref, or a SECURE line in the checker ref, covers nothing. Roles may sign differently (Checker per commit, Security by a line note). Uncovered commits are named by short sha. The dry run prints `line sign: self-deploy will refuse until signed per commit` when a line note covered anything, because `scripts/self-deploy-gate.mjs` keeps its own rule (docs/self-deploy.md). Release now fetches origin's notes refs with a failing fetch stopping the release (Security's LOW on #C1026) instead of reading a stale private copy. The carry (#C1026) is still a single commit's. Tests: `tests/group-sign.test.mjs` (real temporary repositories; every refusal, the tip-only gap, mixed coverage; 10 mutants each fail a test). The release tool is pinned: it ships with the next pack. Not in this commit: the auto-push and stack-ready wait for a group's last card is #C1021 (landed); the same-branch cutting of a group is the builder's practice.

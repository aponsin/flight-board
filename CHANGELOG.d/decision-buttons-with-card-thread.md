- A Decision posted into a card's thread draws its option buttons (decision-buttons-with-card-thread). On 11-17 a Decision Manager posted with `ask(related_thread)` into the thread of a card still in flight showed the owner its text and "Recommended: A" but no buttons, so he could only answer in words: the page read that thread's state as "building" before it read the Decision, and the buttons are drawn only for a "decision" state. A Decision as Manager's last word, with options, is now the thread's state wherever the thread is drawn; a plain last word, the owner's own question, a Decision with no options and an answered Decision read as before. Ships: the page, with the next Worker deploy.

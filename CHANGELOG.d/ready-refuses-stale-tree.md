- READY refuses a tip that would undo work already on main (ready-refuses-stale-tree #C1047): `scripts/stack-ready.mjs` fetches `origin/main` and, before it pushes, lists the files this branch changes that main also changed after the branch's base where the tip's version is not main's. Any such file refuses the READY, naming the files (20 at most, then "and N more") and saying to rebase onto `origin/main`; nothing is pushed and no signal is written. A rename counts as a path gone and a path added, and the file mode counts with the content. Let through: a rebase onto main, a branch cut on main that edits the same files on purpose, a stale branch whose files main has not changed, and the same change made on both sides; with no `origin/main` or no common base nothing is judged. Tests: `tests/ready-refuses-stale-tree.test.mjs`.

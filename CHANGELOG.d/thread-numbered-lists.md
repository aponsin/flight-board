- A numbered list in a thread message, ask or card summary with blank lines between its items is one list that counts up. Before, each blank line closed the list, so every item was an `<ol>` of its own and read "1."; now a blank line between two items of the same kind of list keeps the list going, each numbered item keeps the number it was written with (a list that starts at 3 or skips one reads as written), and the list has 2.2em on the left (was 1.4em) with the numbers outside the text, so a number never covers the first letters. A blank line still separates a list from the text after it. Ships: a page change only. Tests: `tests/thread-numbered-lists.test.mjs` (mutation-checked) (thread-numbered-lists, #C1297).

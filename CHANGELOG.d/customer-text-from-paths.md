- A card whose branch touches the repository's customer-text paths gets its customer-text flag set by the program, so the language review no longer waits on a box someone ticked at card time (customer-text-from-paths, #C1110). The probe (`collector/state.mjs`) reads the branch's changed paths against the repository's `reviewPaths` table: when one matches the `language` list, the card's reading carries `customerText: true` (only ever true; left out otherwise, and for a repository with no table or no `language` list). The Worker (`writeEvidence`, `worker/board-store.mjs`) raises the card's `customer_text` to 1 from empty or 0 and never clears it, so a later reading or a test-only follow-up commit does not take it back (a hand write of false is still the lead's, and the next reading raises it again). Ships as a Worker deploy and the owner's pack (the pinned `collector/state.mjs` and `collector/state-schema.mjs`). Tests: `tests/customer-text-from-paths.test.mjs`.

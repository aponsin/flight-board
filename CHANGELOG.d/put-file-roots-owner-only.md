- The screenshot upload script takes the folders a file may come from only from the owner's own board config (put-file-roots-owner-only, #C1174). `scripts/put-file.mjs` read `fileRoots` from whatever `--config` the command named, so a config an agent wrote could widen which folders a file is uploaded from, and every stored file is readable by every agent past Access. As for the board's address (#C1170), `fileRoots` now counts only from a board config the owner's hooks name in `~/.claude/settings.json` (real paths), and `~/` and the home folder are the account's (`os.userInfo`), never `$HOME`. Any other config still has its own folder as a root and still has to be JSON, but its `fileRoots` is ignored. Pinned file (`scripts/put-file.mjs`), so it rides the next owner pack.

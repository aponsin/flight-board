- `scripts/changelog.mjs` follows no symbolic link and never crashes on a folder (auto-recut-disjoint-stale-tip, #C906, first commit; Security's LOW and Checker 2's LOW on #C1019, to be fixed before anything runs `--write`). It reads `CHANGELOG.d`, each entry in it and `CHANGELOG.md` by lstat: `CHANGELOG.d` must be a plain folder and each entry a plain file, and `CHANGELOG.md` a plain file for a join or a fold; anything else (a symbolic link, a dangling one, a folder inside `CHANGELOG.d`, a special file) is refused and named (`<name>: must be a plain file, not a symbolic link`), nothing is written and nothing is deleted. Before, a committed link could fold a one-line file from outside the repository into `CHANGELOG.md`, or make `--write` delete files outside it, and a folder inside `CHANGELOG.d` threw EISDIR. Tests: `tests/changelog-links.test.mjs` (mutation-checked: following links, the `CHANGELOG.md` check and the `CHANGELOG.d` check each fail a test).

- `scripts/changelog.mjs` follows no symbolic link and never crashes on a folder (auto-recut-disjoint-stale-tip, #C906, first commit; Security's LOW and Checker 2's LOW on #C1019, to be fixed before anything runs `--write`). It reads `CHANGELOG.d`, each entry in it and `CHANGELOG.md` by lstat: `CHANGELOG.d` must be a plain folder and each entry a plain file, and `CHANGELOG.md` a plain file for a join or a fold; anything else (a symbolic link, a dangling one, a folder inside `CHANGELOG.d`, a special file) is refused and named (`<name>: must be a plain file, not a symbolic link`), nothing is written and nothing is deleted. Before, a committed link could fold a one-line file from outside the repository into `CHANGELOG.md`, or make `--write` delete files outside it, and a folder inside `CHANGELOG.d` threw EISDIR. Tests: `tests/changelog-links.test.mjs` (mutation-checked: following links, the `CHANGELOG.md` check and the `CHANGELOG.d` check each fail a test). Second part: `scripts/board-recut.mjs [--dry-run]` re-cuts a signed card that no longer continues main, for the builder to run in the checkout (it only uses a temporary worktree). For the newest `build/<card>[-vN]` branch of each card on origin whose tip holds Checker's PASS and Security's SECURE (read from origin's notes, fetched into private refs), is not on main and does not continue it: if the landings since the tip's base touched none of the files the tip changed (per commit, so a file changed and changed back still counts), it cherry-picks the tip's commits onto `origin/main` and, only when no pick conflicts or comes out empty and every copy has the same message, changed paths, modes and blobs as its original, pushes `build/<card>-v(N+1)` (a new branch, never forced) and prints `old -> new`; any other case prints `needs a human re-cut (why)` and touches nothing, and a merge commit on the line is such a case. It never writes, copies or forges a note, so the new tip needs the reviewers' range-diff re-sign. Like the release tool it acts only on tips holding both PASS and SECURE, so a Quick card (no Security note) is never re-cut by it; its builder re-cuts by hand. Tests: `tests/board-recut.test.mjs` on temporary origin and clone repositories (mutation-checked: the overlap check, the signed check, the copy-equality check, the dry-run push guard, the merge check and the per-commit read of the tip's files each fail a test). Third part: a changelog fragment `CHANGELOG.d/<name>.md` (a `.md` file directly in the folder) is documentation like `CHANGELOG.md` in `DOCS_ONLY` of `collector/state.mjs` (a landing of fragments, docs and tests needs no install) and in the docs group of `scripts/make-pair.mjs`; a script, a nested path or a look-alike name in `CHANGELOG.d` is not. Tests: `tests/changelog-d-docs-only.test.mjs` (mutation-checked: the old pattern, a pattern that accepts nested paths and the make-pair pattern each fail a test).

- The idle-agent stall no longer fires for a session that is running (11-16/17: "Boardsmith idle since 11:14 pm" and "Builder idle since 10:25 pm" woke Manager while both were working on the card the line named). The roster's idle reading can lag the session, so `stalledWaits` (`worker/board-rules.mjs`) now also reads the role's newest `lastActivityAt` from the probe: a role active inside the stall time (15 min) raises no line, for a queued card or a phase wait; a role quiet for the whole stall time still stalls, and a blind reading with no usable `lastActivityAt` reads as before (the idle `since` decides) (stall-reads-live-running, #C1143). Ships: a Worker deploy. Tests: `tests/stall-reads-live-running.test.mjs`.

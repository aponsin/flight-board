- A commit whose Board-Id is not a card id is refused before it is made (ship-banner-stale-row, #C1285; the board said "Release is shipping" 20 minutes after #C1274 was live). Cause: #C1274's commit said `Board-Id: C1274`, not the card's id and not a lowercase id the landing job reads; its branches were deleted at the ship, so nothing could find the card, the collector read it no head and no phase, and the store kept its last row (shipping true) until the card was closed by hand. `gate/first-push.mjs` (the first-push PreToolUse hook): a Bash `git commit` whose message, as typed in the command, has a Board-Id value outside the card-id shape (lowercase letters, digits and hyphens, 64 at most: the collector's BOARD_ID_SHAPE) is refused with the right form and an example. Text only, no git call, so it holds in a product's repository too. Not read, so let through: a message read from a file (-F), a placeholder or a shell expansion, an empty value, and any command that is not a commit (a grep or a log that mentions a Board-Id). Not changed: the collector, the page and the store (the owner wants no guess about a card with no head), the shape itself, the landing job. The hook is installed from the pack, so this needs the next hooks pack. Tests: `tests/board-id-shape-at-commit.test.mjs`.

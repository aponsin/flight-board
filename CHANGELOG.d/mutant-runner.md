- A mutant runner replaces the hand-run mutation check (mutant-runner, #C1115 part 1). `node scripts/mutant-run.mjs --spec mutants.json` takes the builder's list of each new guard (file, line, the text to change, the tests that must catch it), refuses an edit that matches nothing, applies each in a temp copy, runs only the named tests, 8 at a time, and requires a failure; a mutant they miss is re-run against the full suite and is a survivor only if that passes too. It ends with "mutation check: pass" or "mutation check: FAIL" and writes the time each mutant took (`--out`). Before, 30 mutants meant 30 full-suite runs, about 75 minutes. Ships with nothing to deploy. Tests: `tests/mutant-run.test.mjs`. The review ETA that counts mutants follows.

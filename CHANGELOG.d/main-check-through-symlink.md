- Board scripts now run when called through a symlink: `node ~/.flight-board/current/scripts/group-check.mjs read ...` used to do nothing and exit 0, because the script compared the path as typed (the link) with its real file. One helper, `isMain(import.meta.url)` in `scripts/is-main.mjs`, compares both by real path, and eleven scripts that compared the typed path now use it (`group-check`, `changelog`, `data-fragments`, `make-pair`, `push-keys`, `mutant-run`, `pair/make-pair`, `probe-board`, `probe-evidence`; the fence and the `post-commit-push` git hook do the same inline, since the fence's imports are pinned to two files and the hook imports nothing of ours); a lint fails any new script that compares `process.argv[1]` without a real path (main-check-through-symlink, #C1167).

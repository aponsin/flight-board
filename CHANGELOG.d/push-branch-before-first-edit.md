- A PreToolUse hook (`gate/first-push.mjs`) refuses the first edit on a card branch that origin does not have yet, with "Push this branch first (an empty commit is fine): the board counts a card as started from its first push". It watches Edit, Write, MultiEdit, NotebookEdit and the file writes of Bash (redirections, tee, sed -i, cp, mv, rm, touch, mkdir); it allows git commands themselves, files outside any repository, anything inside `.git`, branches that are not card branches (main, dev, manager/ ...), a detached HEAD, and every doubt (a config or call it cannot read). It runs git only in the checkouts the board config names (`collector.repoPath`, `collector.repos[].path`, `collector.refresh.repos`; a linked worktree counts through its `.git` file, read as a file), so a repository it does not name, with its own hostile `core.sshCommand`, runs nothing; and it never asks the remote (the remote-tracking ref only, which `git push` writes). `scripts/hooks.mjs` writes its entry beside the Stop one, and `scripts/make-pair.mjs` moves the hooks step's read-back to expect both (a template with no line to move it by is refused, never half moved) (push-branch-before-first-edit, #C1065). Ships: the hooks pack (owner install, quit and reopen the app). Tests: `tests/first-push-guard.test.mjs`, `tests/hooks-store.test.mjs`, `tests/make-pair-hooks-store-only.test.mjs`.

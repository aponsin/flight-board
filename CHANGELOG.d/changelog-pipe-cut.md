- `scripts/changelog.mjs` in print mode (no flag) is no longer cut at 64 KB when its output goes to a pipe (#C1155, Checker 2's LOW on #C1153): the command line ended with `process.exit`, which stopped the process before a slow reader had taken the joined CHANGELOG.md, the same bug #C1153 fixed in `scripts/data-fragments.mjs`. It now sets `process.exitCode` and ends by itself, so the pipe drains first. The other scripts that call `process.exit` after printing write one line or a short JSON list, far under the pipe's 64 KB, so none is cut. Tests: `tests/changelog-per-card.test.mjs` (a copy of the script prints a CHANGELOG.md of over 150 KB to a reader that holds back its first read; mutation check: with `process.exit` back, the test gets 0 characters).

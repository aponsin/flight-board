- An agent can no longer close a thread the owner has not had the last word on (close-only-after-owner #C1046): the store refuses an agent's `ask_close` (`close-not-after-owner`, logged) unless the newest message on the ask's thread is the owner's, and the refusal says to post and leave the thread for him. The owner closes at any time, and an agent closes right after his own last message (Ack, Done, Closed). One exception, a judgment call noted for review: an Approval, which the Reviewer closes when its pull request is merged or a newer head replaces it with no word from the owner. An agent's `post` already carries no `resolved`, so there is no other way for an agent to close a thread. Tests: `tests/close-only-after-owner.test.mjs`; six older tests that closed as an agent now give the owner's word first.

- "Signed" now means the same everywhere: a review's note signs a commit only when its first line starts with the role's word (PASS for Checker, SECURE for Security). The probe, the landing job, the re-cut tool, the release tool and the self-deploy gate all read it through one function, and sign-note refuses any other first word (HOLD, "looks fine"), so a note that read as signed on the board can no longer leave a card the landing job never picks. A card of the board's own repository now always has Security's review, in the dispatch, the probe and the level the page shows (signed-means-pass-secure, #C1163). Ships: a probe and Worker deploy, plus script changes that ride the next owner pack. Tests: `tests/signed-means-pass-secure.test.mjs`.

- `scripts/data-fragments.mjs` in print mode (no flag) is no longer cut at 64 KB when its output goes to a pipe (#C1153, Checker 2's LOW on #C1152): the command line set its exit code with `process.exit`, which ended the process before a slow reader had taken the folded DATA.md (65,284 of 151,661 characters came through). It now sets `process.exitCode` and ends by itself, so the pipe drains first.

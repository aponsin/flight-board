- A git note or message that names a commit id is no longer refused as a phone number (scan-skips-hex-commit-ids, #C1096). About one commit id in a hundred holds ten digits in a row, and the pre-push scan's phone rule read them as a phone, so a line sign-off from main's tip of 11-16 could not be pushed and Release's dry runs stopped on three signed branches. The phone rule now skips a whole hex token of 12 to 40 characters; a bare digit run and every phone shape are still refused, and the other rules (email, token, listed words, artifact link) read the line as before. Ships: the pre-push hook uses the checkout's own copy at once; the release tool's copy is pinned and rides the next owner pack. Tests: `tests/scan-skips-commit-ids.test.mjs`.

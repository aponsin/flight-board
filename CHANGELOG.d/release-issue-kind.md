- A card now counts release issues (release-issue-kind, #C1212). When a ship of a card stops for a reason that is not the card's own code (the ship tool refuses it, the DECISIONS or CHANGELOG merge goes wrong, the ship stops, or a re-sign is missing after a main merge), Manager adds 1 to the card's `release` count, and the card shows it beside its other counts as "2 release". Before, those stops were counted nowhere, so a card that shipped on the third try looked like a clean one. `card_create` and `card_update` take `issues.release` (0 to 99). Ships: a Worker deploy and the page; no migration. Tests: `tests/release-issue-kind.test.mjs`, `tests/issue-kinds.test.mjs`.

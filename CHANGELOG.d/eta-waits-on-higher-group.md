- A group's "Live in" time never comes before a higher group's of the same agent, and a build with no work seen counts as not started (eta-waits-on-higher-group, #C1099). On 11-16 the board showed G6 (Boardsmith's) "Live in 54 min" and G10, first in the owner's order and also Boardsmith's, "1 h 52 min", and the owner read it as the order not being respected. Two causes, both in the page's estimate: a group's time ignored that an agent works its groups in the owner's order, and a card whose build had started on 11-12 and then sat behind another group counted days of build as spent, so it showed only a few minutes left. Now a group's live time is at least 5 minutes after the latest adjusted time of every group above it (in the owner's order) that shares an agent with it, and a card on the store whose build start has no work seen since (nothing pushed) counts no build time as spent, so its whole build median is still ahead; the clock runs again from the first push. Groups of different agents do not move each other. Tests: `tests/eta-waits-on-higher-group.test.mjs`.

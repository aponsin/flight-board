1. Plan. Run: node {{CURRENT}}/collector/collect.mjs --config {{CONFIG}} --prepare
   It prints "Export the board into: your scratchpad folder + /flight-board-export", then "Mode: off." (stop: that is the whole run), or a "Mode:" line with some "Query <collection>: where <condition>" lines and perhaps one "Sweep <collection>: limit <n>, cursor <cursor or none>" line. 2. Read and save. Use the database tools (ToolSearch loads them: db_query, db_list, db_get, db_write of the board's server) on this board only.    - For the "Sweep" line, if there is one: read ONE page only and do not follow nextCursor. For steps use db_query with the line's limit and where; for any other collection db_list with the line's limit; add the cursor only when the line gives one. Save it as Export/sweep/<collection>/p1.page.json (none if it came back empty). Then always save Export/sweep-next.json as {"collection": "<the sweep collection>", "next": <the nextCursor the answer gave, or null when it gave none>}.

3. Publish. Read {{OUT}}/derived-all.json (the Read tool, the whole file). db_write one operation: set derived/all with data equal to that file's content, copied exactly, and ifVersion the version you noted (no ifVersion if it was null). If the file is not there, or the write is refused because the version moved, stop: the next run does it. That is the whole run.

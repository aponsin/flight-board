- 2026-11-20: One-time repair of the product cards' false install waits and early closes (#C1379, the owner's pick A on #T2194; Director's audit #C1375: 93 product cards had an "owner's install" wait that does not exist for the product, and 71 had closed at "ship", before their deploy). No definition changes (#C1378 changed it). Migration `0040_repair_false_install_waits.sql` removes the `phase_history` rows with wait `install` and source `evidence` (the store's own evidence write) of every card whose repository word is a product repository (`repoKind`, `worker/board-rules.mjs`): a start and its end alike, because a closed false wait still bends the install-time medians. The rule is written once, `worker/repair-false-install-waits.mjs` (`DELETE_FALSE_WAITS`), and the migration holds it verbatim (a test holds them equal); `scripts/repair-false-install-waits.mjs <view.json>` runs the same rule as a dry run over the board view the connector's `read_view` saved, prints every card and row the migration will remove, and changes nothing. No card row changes: `done_at`, `done_evidence`, the stored reading and the phase stay, nothing is reopened. The board card's install waits, the probe's own rows and the step tool's waits are untouched. Idempotent: a second run finds no row. A deleted row cannot be undone, so the pack note carries the dry-run list. The 71 closed product cards (stored reading `ship`) are read again by the collector (`collector/state.mjs` `rereadClosed`): a done, undropped card with a named non-board repository word, closed within 14 days of done_at (and a card that never reads live is not read after that), is read with the open cards until a run reads it live; those that have are remembered in `closed-live.json` in the state folder and not read again. Its live reading and version reach the store through the ordinary evidence write, which closes nothing (the card is already done). Ships as a Worker deploy (the migration) and a pack (the collector is pinned). Tests: `tests/repair-false-install-waits.test.mjs`, `tests/closed-product-cards-reread.test.mjs`.

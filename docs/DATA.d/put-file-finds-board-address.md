- 2026-11-17: The screenshot upload script finds the board's address in the board config (#C1170). On 11-17 Mainsite could not put four home page screenshots on the board: `scripts/put-file.mjs` stopped with "the board's address must be https://<host> (BOARD_BASE_URL in the env file)", and no env file on this Mac had that line, so #C1056's upload had never worked for an agent. The address is now the board config's `storeUrl` (read only from a board config the owner's hooks name: the `--config` paths in the hook commands of `~/.claude/settings.json`, by real path; the `storeUrl` of any other `--config` file is ignored, because `--config` is a command-line choice and a file an agent wrote could name any host and receive the token (Security's S1); the config also names the folders a file may come from), so an env file holding only `BOARD_SERVICE_TOKEN_ID` and `BOARD_SERVICE_TOKEN_SECRET` works. A `BOARD_BASE_URL` line in the env file is still accepted; when both are there and name different hosts the upload is refused, so the token goes only to a host the owner wrote in a file. Only `https://<host>` (and an optional port) is an address; the command line still has no way to name a host (`--base` is refused); each refusal names the file it read. Tests: `tests/agent-attaches-local-file.test.mjs`. Touches no definition in this file: the upload is a program, not a note (principle 1).

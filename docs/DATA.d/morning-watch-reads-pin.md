The name is one of the two, never a path; no single pin, a pinned install without the script, or a script that is a link out of the install means nothing is run and the exit code is 1; otherwise the script's output and exit code pass through. The entry's path holds no commit, so a rule or a task step that names it is the same text for every pack. Touches no definition in this file (principle 1: a program reads the pin, never a note).

- 2026-11-20: The agent's pull request list follows GitHub (#C1389). New evidence key `prs`, written by the probe only: `{ at, repos, open }`, where `repos` is the repositories (`owner/name`, at most 10) whose open pull requests the probe read in full, `open` the open pull requests of those repositories (`owner/name#number`, at most 400) and `at` the time of the read. A repository whose read failed, or whose list filled the 200 cap, is not in `repos`. The panel of the agent's pull requests (`agentPrs` and `approvals` of the compat answer) leaves out an Approval ask whose link names a repository in `repos` and a pull request not in `open`, when the ask was made at or before `at`; with no `prs`, or no such repository, nothing is left out. The asks themselves are not changed or closed, and Release's check of an approval reads the asks, not the panel. Also, a closed card's reading in `readings` carries `closedAt` (the card's done_at, epoch ms) beside `closed: true` (#C1399, Checker 2's F1: the truth check reads the close time from it). Ships as a Worker deploy and a probe tree step; no migration. Tests: `tests/approvals-drop-closed-prs.test.mjs`, `tests/truth-check.test.mjs`.

- 2026-11-17: A thread's state is "decision" whenever Manager's last word is a Decision with options, even on the thread of a card still in flight (decision-buttons-with-card-thread). Before, a card in flight made the thread "building" ahead of everything but the owner's open question, so a Decision posted there (by `ask` with `related_thread`) drew its text and "Recommended" but no buttons. The order is now: the owner's open question, a Decision with options as Manager's last word, a card in flight (building), then Manager's last word by its kind (live, decision, answer). Nothing else about a thread's state changes: a plain last word, a Decision with no options and an answered Decision read as before. Touches no definition in this file; the buttons are what the board guarantees for a Decision (principle 1: the page draws them, a note does not). Tests: `tests/decision-buttons-with-card-thread.test.mjs`.

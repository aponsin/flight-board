- 2026-11-19: A Terminal or Action ask can name the owner's thread (#C1317, the Ask types row: a small extension, no definition change). Manager's Terminal or Action ask takes an optional `related_thread`, as a Decision does: an owner thread's id, or `"none"` (the same as leaving it out). A known thread keeps the ask as one ask (answered, Done and closed as before) and records the id in its body; the view's waiting doc carries it as `thread`, and the page draws the ask inside that thread instead of as a row of its own: the thread reads "waiting on you" until the ask is answered, and the ask is left out of Needs you and With the team. An unknown thread is refused as `click-thread-unknown`, an empty or non-text value as `click-thread-shape`; other roles still get `unknown-field`. No schema change (the id lives in the ask's body JSON). Worker and page change, no probe file. Tests: `tests/click-ask-in-owner-thread.test.mjs`.

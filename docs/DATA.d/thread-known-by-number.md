- 2026-11-18: `from_thread` on a card is a thread's number, and a thread is known by that number when it is an ask's number, a message thread `t<number>`, or a row of threads with that number and at least one message (thread-known-by-number). A thread the owner opens has an id of its own (`t-<ms>`) and its number in threads.num, so before this its number found nothing and a card that changes a definition was refused though the owner had decided it there. Nothing else about the rule changes: existence of the thread is all it checks (a card with no summary is explained by it the same way). Touches no definition in this file (principle 1: the gate reads the thread from the store). Tests: `tests/thread-known-by-number.test.mjs`.

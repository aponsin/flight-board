- 2026-11-20: "Started = first push" reads a re-cut branch by its name (#C1325; a bug fix, no definition change). The probe matched a card to a pushed tip by the tip's Board-Id trailer, by the last part of the branch name equal to the card id, or by the card number. A re-cut is named `<id>-v<N>`, so its last part is not the id and a tip with no usable trailer matched nothing: the card read as having nothing pushed and its builder was woken with "has nothing pushed". `headsFor` now also matches a branch whose last part, with one trailing `-v<N>` (1 to 3 digits) removed, is the card id (`slugOfBranch`). A different slug that only ends with or starts with the id, and a suffix that is not a version, still match nothing; the newest version of a family is still the card's row. The probe's file `collector/state.mjs` is pinned, so this rides an owner pack. Tests: `tests/dispatch-sees-v2-branches.test.mjs`.

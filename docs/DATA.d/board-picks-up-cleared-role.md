- 2026-11-16: The watchdog picks up a role that cleared itself (board-picks-up-cleared-role, #C870). `scripts/pickup-watch.mjs` gains `passActions(rows)` and the command `--pass '<rows JSON>'` (exports `REARM_TEXT`); `decide()` and its one-role command are unchanged. A row is `{role, state, tokens, reset, pickedUp, watchRunning, remoteControl}`; the answer is a JSON list of `{role, do: "send_message", text}` or `{role, do: "set_remote_control", on: true}`. `/pickup <Role>` only when `reset` is true, `pickedUp` is not, the role is idle and its Messages tokens are under `FRESH` (5000); "arm your dispatch watch" when `pickedUp`, idle and `watchRunning` is not true; set Remote Control on when it reads "off". A role name not of the ROLE form (letters and digits, single spaces inside) and an unreadable row are dropped. No Worker, store or migration change: the local agent watchdog task reads the rows with `list_sessions`, `get_usage` and its own reset and watch readings, runs the command and does what it prints (the prompt text is `docs/watchdog-pickup-pass.md`). Tests: `tests/pickup-pass.test.mjs`.

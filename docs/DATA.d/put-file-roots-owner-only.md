- 2026-11-17: The screenshot upload script trusts a board config's `fileRoots` only from the owner's own config (#C1174). Checker 2 found in the #C1170 review that `scripts/put-file.mjs` still took the folders a file may come from (`fileRoots`) from any `--config` a caller passed, which is a command-line choice: a config an agent wrote could widen the folders, and every stored file is readable by every agent past Access. Security found that the folder holding the config was a root too. The rule of #C1170 for the address now covers the folders: they come only from a board config the owner's hooks name (the `--config` paths in the hook commands of `~/.claude/settings.json`, by real path), the config's own folder and its `fileRoots`, and `~/` and the home folder are the account's (`os.userInfo`), never `$HOME`. Any other config gives no folder: the upload is refused, naming the file. Tests: `tests/agent-attaches-local-file.test.mjs`. Touches no definition in this file: the upload is a program, not a note (principle 1).

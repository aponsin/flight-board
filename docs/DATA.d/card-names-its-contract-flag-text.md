- 2026-11-17: `changes_definition` may arrive as the text "true" or "false" through the card tools (#C1169 follow-up). No session could create a flight-board card on 11-17: the tool list a session holds was fetched before the schema named `contract` and `changes_definition`, and a client with no type for the field sent the boolean as text, which the rule above refused. At the tool door (`card_create` and `card_update`) exactly the text "true" and "false" are read as the booleans, so the stored value and the rule are as before: a flight-board card still needs `contract` and a boolean `changes_definition`, and `true` still needs a known `from_thread`; any other text is refused with `card-flag`.

- 2026-11-19: The landing recipe gains a folder cleanup (#C1318; no definition change). After the land job's run writes its report, each card it landed has its builder worktree removed (`landedFolders` in `scripts/board-land.mjs`): a linked worktree of the repository (never its own folder or the folder the job runs in) on the landed branch or on `[build/]<card id>[-vN]` whose HEAD is an ancestor of origin/main, removed by plain `git worktree remove` (never `--force`, so git itself refuses a folder with unsaved changes or a lock). A refusal prints `folder kept <path>: <reason>` and one ready line for the owner (`git -C <repo> worktree remove <path>`) and never fails the land; a dry run removes nothing. The report's `landed` entries now carry `cards`. Builders still make their folders in `~/Documents/Code` as before. The land job's file is pinned, so this rides an owner pack. Tests: `tests/land-removes-card-folder.test.mjs`.
